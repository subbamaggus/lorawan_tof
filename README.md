# lorawan_tof

since i want to improve my skills, i thought i use a small project to implement a sensor that i can and will use.

the project covers developing a board and according software for a time of flight sensor with connection over lorawan to monitor the levels of my oil tank.

the functionality is basically the same as:
https://www.dragino.com/products/distance-level-sensor/item/276-lds12-lb-ls.html


# requirements

battery/akku driven

attachable tof sensor

lorawan network usage TTN (maybe later local lorawan-mqtt connection)

design pcb

design housing

own firmware

low cost

small formfactor
